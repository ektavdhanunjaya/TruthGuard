# TruthGuard

## Self-Verifying RAG Engine for Real-Time Hallucination Recognition and Mitigation

TruthGuard is a self-verifying Retrieval-Augmented Generation (RAG) system designed to detect, assess, and mitigate potential hallucinations in Large Language Model responses.

## Project Structure

- `backend/` - FastAPI backend
- `frontend/` - React frontend
- `data/` - Documents and evaluation datasets
- `evaluation/` - Evaluation scripts and results
- `docs/` - Project documentation

## Technology Stack

- Python 3.11
- FastAPI
- React
- Node.js 20
- RAG
- ChromaDB
- Sentence Transformers
- Large Language Model
